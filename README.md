# Full Stack Open

This repository contains my solutions and projects completed while working through the **Full Stack Open** course by the University of Helsinki.

The course focuses on modern web application development using JavaScript, React, Node.js, Express, REST APIs, databases, and other full-stack technologies.

## 🚀 Running the Projects Locally

Clone the repository:

```bash
git clone https://github.com/riyaBodwani/Full-stack-open.git
cd Full-stack-open
```

Navigate to the project you want to run and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

For the Phonebook backend:

```bash
npm start
```
